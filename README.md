# Python 101 · Tarayıcı Laboratuvarı

Forenly AI Academy **Python 101** kursunun çalışma ortamı. Bilgisayarına hiçbir şey kurmadan, tarayıcıda Python 3.14 ile çalışırsın.

## Başlat

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ForenlyAI/python101-browser-lab)

Ya da bu sayfada: **Code → Codespaces → Create codespace on main**.

Ortam açılınca solda `ilk-adim` klasörü görünür: 1. haftanın dosyalarını buraya yazarsın. Alttaki terminalde sürümü kontrol et:

```
python --version
```

`sales_report/` klasörü örnek bir projedir: `cd ../sales_report && python report.py`

## İşin bitince

Ücretsiz hesapta Codespaces her ay sınırlı süre verir. Çalışma alanını durdurmak için: [github.com/codespaces](https://github.com/codespaces) → çalışma alanının yanındaki **…** → **Stop codespace**.
